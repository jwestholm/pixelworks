# Pixel Works – NOW / NEXT / LATER efter v0.13.4

## NOW – implementerat / kontrollerat lokalt
- Gemensam studio från 0.13 med explicit personalförflyttning bevarad.
- Codex-ledd planering (redan 0.13.3) kompletterad med redigerbart, samlat utkast och ett godkännande innan flera uppgifter startar.
- Tillgänglig bemanning och beroenden visas i planvyn. Saknad programmerare för ett nytt delat projekt görs begriplig.
- Nya projekt får automatiskt Game Bible + spelbar HTML5-startprototyp + lokal Git-baslinje, utan nätverksanrop.
- Befintliga projekt med kod är skyddade mot automatisk bootstrap.
- 28 riktade backendtester och två Chromium-smoketester godkända.

## NEXT – hög prioritet
- Verifiera live med riktig Codex-session och de specifika Google/Gemini-medarbeterna hos användaren.
- Ersätt parallella äldre schemaläggare med en gemensam arbetsmotor med transaktionssäker körning, återstart och beroendekontroll.
- Utöka vertikala prototyper per spelgenre; förbättra nyprojektsguilen med explicit första release-/testmål.
- Visa tydliga AI-blockeringar på varje arbetsorder (exakt behörighet, kvot, verktyg, Git, saknad personal) och åtgärdsknapp.
- Gör hela historiska regressionstestsviten grön, inte bara riktade tester.

## LATER
- Story Mode med progressionssystem skilt från verkliga API-kvoter.
- Publicerbara HTML5-versioner, export och säker delning.
- Färdig permanent studio-roster med flera samtidiga projekt och seriös produktionsplanering.
