# Pixel Works – CURRENT STATE (v0.13.5)

- **Fungerande bas:** v0.13.4 har en gemensam kontorsvy, projektvis fördelade anställda, lokal HTML5-startprototyp, Game Bible, personalbaserad delegering, Codex-/Gemini-adaptrar samt redigerbara produktionsplaner.
- **NYTT NOW:** befintlig studiobehörighet räcker för att Chefen ska få släppa fri validerade flerstegsplaner automatiskt. Gamla 0.13.4-utkast släpps fria av normal köavstämning. Färdiga rådgivande uppdragsrapporter kan lämnas vidare som uttryckligen ej godkänd referensdata, utan extra kreativt godkännandestopp.
- **Oförändrade skydd:** verklig kod kräver Git-isolering och verifierad integrering; autentisering, projekttillstånd, Google-kvot, personalbehörighet och inga externa pushar gäller fortsatt.
- **Begränsning:** inte samma sak som att visionbeslut i Game Bible är automatiskt godkända. Frivillig rapportgranskning ligger kvar.
- **Verifikation:** 20 nya offlinebackendtester + 28 äldre riktade tester i separata körningar. Två Chromium-smokes. Ingen liveverifikation av privata leverantörer.
