# NOW / NEXT / LATER – Pixel Works v0.12.11.17

## NOW – levererat
- Projektets identitet stannar kvar vid personaluppdateringar. Senaste projekt återställs bara vid första laddning.
- Spelprojektet visas på skärmen och i beslutsdialogerna; gamla projektbaserade skrivningar blockeras där de använder det gemensamma API:t.
- Befintlig Wizard eller egen spelidé är bevarad och följs av tydlig projektintroduktion.
- Studioåtkomst kan aktiveras med ett enda uttryckligt beslut. Om tillstånd redan finns fortsätter det gälla.
- Aktuella beslut syns från högerspalten; arbetsbord visar fullständiga namn och hjälptexter.
