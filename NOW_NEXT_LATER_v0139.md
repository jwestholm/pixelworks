# Pixel Works v0.13.9 – NOW / NEXT / LATER

## NOW (utfört)
- Ämnesanteckningar från spelägaren visas som egen replik och ingår i AI-kontext med korrekt avsändare.
- Spelägaren kan skicka nya kommentarer i aktiv fikadiskussion, eller starta max två riktiga AI-svarsturer efter avslut.
- 👍 / 👎 per verkligt AI-svar; per-svar-idempotent **Gör till uppdrag**, med explicit stationsval.
- Samtalsdata och projekt/behörighetsgränser bibehålls; riktade backend- och webbläsartester gröna.

## NEXT

- En enda gemensam arbetsmotor utan äldre konkurrerande schemaläggare.
- Fullständig och grön regressionstestsvit inklusive verkliga UI-navigationer och projektbyte.

## LATER
